# 📈 Stock Portfolio Tracker

## 📌 Project Overview
The **Stock Portfolio Tracker** is a Python-based project developed as part of my **CodeAlpha Python Programming Internship**.

This project helps users track their stock investments, calculate the total investment value, and view portfolio performance using stock prices and quantities.

## ✨ Features
- Add stocks to a portfolio
- Specify stock quantity
- Track stock prices
- Calculate total investment value
- Display portfolio summary
- Export portfolio details to a CSV file

## 🛠️ Technologies Used
- **Python**
- **CSV (Comma-Separated Values)**

## 📂 Project Structure

Task2_Stock_Portfolio/
  1. stock_portfolio.py
  2. portfolio_result.csv
  3. README.md


## 🚀 How to Run the Project

### Step 1: Clone the Repository

git clone https://github.com/TruptiGarud/CodeAlpha_Stock_Portfolio.git


### Step 2: Navigate to the Project Folder

cd CodeAlpha_Stock_Portfolio


### Step 3: Run the Python Program

python stock_portfolio.py


## 📊 Output
The program calculates the total value of the stock portfolio and saves the portfolio details in a CSV file named `portfolio_result.csv`.
